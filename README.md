# Employee-Wellness-Analysis
Exploratory Data Analysis (EDA) is a crucial step in the data analysis process, enabling us to summarize the main characteristics of a dataset and uncover patterns with the help of visualizations and summary statistics. This project aims to perform EDA on various datasets, draw meaningful insights and present their findings effectively.
# Aim
The goal is to design and implement a well-structured relational database for an e-commerce platform using SQL and to develop a set of advanced SQL queries that:
1) Identify popular products, top customers and revenue trends.
2) Analyze customer spending habits and purchase frequency.
3) Evaluate product performance based on sales, reviews and stock levels.
4) Generate operational insights such as shipment timelines, discount usage and order statuses.
5) Provide actionable insights for inventory management, including low-stock alerts and unsold inventory.
